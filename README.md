# Бот расчёта КП по 1С/БИТ (офис Марксистская)

## Как запустить — 3 шага

### Шаг 1. Залей папку на GitHub
1. Зайди на https://github.com — войди в свой аккаунт (или зарегистрируй, если нет).
2. Нажми зелёную кнопку **«New»** (слева) или **«Create repository»**.
3. Назови репозиторий, например: `kp-bot` (любое имя). Можешь не ставить галочку «Add a README».
4. Нажми **«Create repository»**.
5. На следующей странице увидишь блок **«…or upload an existing file from your computer»** — нажми ссылку **«uploading an existing file»**.
6. **Перетащи мышкой** (или нажми «choose your files») **все файлы из папки** `C:\проекты\отчет тм\бот-кп\` — кроме файла `.env` (его НЕ загружай, он только на твоём компьютере).
7. Прокрути вниз, нажми **«Commit changes»**.

✅ Папка загружена.

### Шаг 2. Запусти на Railway (бесплатный хостинг)
1. Зайди на https://railway.app — нажми **«Login»** → **«Continue with GitHub»** → разреши доступ.
2. После входа нажми **«New Project»** → **«Deploy from GitHub repo»**.
3. Выбери репозиторий `kp-bot` (который создала в шаге 1).
4. Railway сам найдёт Dockerfile и начнёт сборку. Подожди ~2 минуты.
5. Когда соберётся — появится зелёный кружок **«Deployed»**.
6. Сверху нажми на вкладку **«Variables»** (или «Settings» → «Variables»).
7. Добавь переменные (нажми **«New Variable»**):
   - `BOT_TOKEN` → вставь токен вида `8899240305:AAEgTbuMqUl9S014nXTiAp2381VgUyqCU20` (какой дал BotFather)
   - `RUN_MODE` → `web`
   - `PUBLIC_URL` → не заполняй пока, Railway сам её подставит
   - `ALLOWED_IDS` → если хочешь, чтобы бот был только у сотрудников — укажи их Telegram ID через запятую (например: `123456789,987654321`).
     Оставить пустым = бот доступен всем, так проще для начала.

### Шаг 3. Настрой вебхук
1. На вкладке **«Deployments»** нажми на название последнего деплоя.
2. Найди поле **«Public URL»** (или **«Domains»** → **«Generate Domain»**).
3. Нажми **«Generate Domain»** — появится ссылка вида `https://kp-bot.up.railway.app`.
4. Вернись в **«Variables»**, добавь переменную:
   - `WEBHOOK_URL` = `https://твой-адрес.up.railway.app/webhook` (обязательно `/webhook` в конце)

После добавления переменной Railway перезапустит проект. Жди 30 секунд.

✅ Бот работает! Напиши своему боту в Telegram команду `/start` — он ответит.
